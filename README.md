# Hotel Booking Analytics Dashboard | Power BI

An interactive Power BI dashboard built to analyze hotel booking performance, revenue, pricing, customer behavior, and cancellations.

**Note:** This project uses a synthetic hotel booking dataset generated with the assistance of ChatGPT for data analytics practice and portfolio development. The dataset is intended for demonstration and learning purposes and does not represent real hotel booking records or any specific hotel.

## Project Overview

This project analyses a synthetic hotel booking dataset to explore booking performance, revenue generation, pricing patterns, customer behaviour, and cancellation trends.

## Project Overview

This project analyses hotel booking data to identify patterns in booking activity, revenue generation, pricing, customer segments, and cancellation behaviour.

The dataset required data cleaning and transformation before analysis. Additional helper columns were created to support date-based analysis, booking performance calculations, and dashboard visualisations.

## Dashboard Pages

### 1. Hotel Booking Performance Overview
Provides a high-level view of overall booking performance and key business metrics, including booking trends and operational performance.

### 2. Revenue and Pricing Analysis
Analyses revenue generation and pricing patterns across different booking characteristics, helping identify trends in average daily rates and revenue performance.

### 3. Customer Analysis
Explores customer characteristics and booking behaviour to understand different customer segments and their contribution to hotel bookings.

### 4. Cancellation Analysis
Examines cancellation patterns and identifies trends across booking characteristics to understand factors associated with cancellations.

## Key Areas of Analysis

- Booking volume and booking trends
- Revenue performance
- Average Daily Rate (ADR)
- Pricing patterns
- Customer segments
- Cancellation behaviour
- Lead time and booking characteristics
- Hotel booking performance

## Data Preparation

The raw dataset contained inconsistencies and required cleaning before visualisation and analysis.

The data preparation process included:

- Cleaning and standardising date fields
- Handling inconsistent booking and arrival dates
- Creating helper columns for analysis
- Structuring fields for time-based analysis
- Preparing calculated metrics for dashboard reporting
